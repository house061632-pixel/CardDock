# CardDock

Mac 素材過卡與備份工具。支援最多兩張卡同時過檔、SHA-256 校驗、SSD 接續 HDD 備份，以及跨電腦載入 SSD 紀錄。

## 下載

正式下載包準備中，完成簽章、公證與驗證後會放在 [Releases](https://github.com/house061632-pixel/CardDock/releases)。

適用 macOS 13 或更新版本，包含 Apple Silicon 與 Intel 執行檔。Intel 尚未在實機驗證。

## 更新

內建更新功能的版本可從 CardDock 選單檢查更新，也可關閉自動檢查。安裝需使用者操作；過卡、排隊、暫停或校驗進行中不會開始更新。舊版需先手動安裝一次。

## 隱私

素材與工作紀錄留在本機及你指定的磁碟。更新功能會連線 GitHub 取得版本清單與下載檔案，不上傳素材、不傳送系統分析報告；GitHub 仍會接收到一般網路請求資訊，例如 IP 位址。

正式拍攝前請先以測試素材驗證完整流程；檔案校驗不等同於影音內容品質檢查。
